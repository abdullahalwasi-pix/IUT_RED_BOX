# IUT Red Box Modular Structure

```text
IUT_Red_Box
├── assets
├── docs
│   ├── BUILD_INSTRUCTIONS.txt
│   └── NPP_EXEC_SCRIPT.txt
├── include
│   ├── config.h
│   ├── enemy.h
│   ├── game.h
│   └── player.h
├── presentation
├── src
│   ├── enemy.c
│   ├── game.c
│   ├── main.c
│   └── player.c
└── BUILD_AND_RUN.bat
```

`main.c` starts the program. `game.c` coordinates systems. `player.c` contains player logic. `enemy.c` contains Zombie Student logic. Header files stay in `include`.
